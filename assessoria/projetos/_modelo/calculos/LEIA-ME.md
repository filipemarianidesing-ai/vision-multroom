# Cálculos

- Um script Python por cálculo relevante (`calc_<assunto>.py`), importando
  `assessoria/ferramentas/calc/acustica.py`, com entradas no topo e fonte de cada dado.
- Saída do script salva ao lado (`calc_<assunto>.saida.txt`) para rastreabilidade.
- A memória de cálculo do relatório (modelo em `assessoria/modelos/memoria-calculo.md`)
  deve citar o script e reproduzir entradas, fórmula, resultado e limitações.
